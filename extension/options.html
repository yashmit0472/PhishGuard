PhishGuard

1. Pair the local app

Start PhishGuard. Copy its 8-character local pairing code. Never share that code.

2. Connect Gmail

Google grants read access to your mailbox. PhishGuard requests only the message you open, including its headers, body and attachments. It sends that message to the app on this computer for analysis.

Automatic checks

This reads each identifiable open message through Google, including attachments. No mailbox-wide scan runs. Turn this off to use the “Check this email” button instead.

Missing or ambiguous message IDs are not guessed. EML upload remains available in the local app.
